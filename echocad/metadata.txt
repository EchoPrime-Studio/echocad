description=Import AutoCAD DWG drawings into QGIS, keeping CAD layers, colours, line types and text.
about=EchoCad converts DWG drawings by calling LibreDWG's dwg2dxf as a separate process, so no CAD library is bundled with the plugin. The converter is not included: on first run the plugin shows how to obtain it for your platform, or you can point it at an existing installation. Each CAD layer becomes its own QGIS layer, and entity colour, line type, line width and text (size, rotation, colour) are carried over. Supported formats are R14 and newer. Everything runs locally - drawings never leave your machine.
